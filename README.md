## Overview

A production-ready credit scoring MVP designed for Indonesian Credit Union (Koperasi Simpan Pinjam) loan committees. The system goes beyond a simple approve/reject decision — it uses SHAP (SHapley Additive exPlanations) to generate a human-readable audit log explaining *why* the model made its decision, mapping raw ML features to Indonesian financial terminology that a loan committee officer can actually understand and present.

**Key design decision:** Indonesian credit unions have unique evaluation criteria beyond standard 5C analysis — RAT attendance, cooperative education certification (Diksar), and social guarantors. These "cultural" features are first-class inputs to the model alongside standard financial metrics.

## Features

### ML Engine
- **XGBoost Classifier** — gradient boosted trees optimized for tabular credit data
- **SHAP TreeExplainer** — exact Shapley values for full model transparency
- **Natural language audit report** — SHAP values translated to Indonesian banking terminology, ready for committee presentation
- **Feature importance analysis** — identifies top 3 approval drivers and top 3 risk factors per application

### Cooperative-Specific Features (beyond standard 5C)
The model includes three cultural features unique to Indonesian Koperasi that traditional bank scoring ignores:

| Feature | Description | Impact |
|---|---|---|
| `persentase_kehadiran_rat` | RAT (Annual Member Meeting) attendance % | +0.015 per % |
| `lulus_diksar` | Cooperative education certification | +0.80 boost |
| `ada_penjamin` | Social guarantor availability | +1.50 boost |

### Frontend Dashboard
- Real-time SHAP audit log with animated line-by-line rendering
- SVG circular score gauge with smooth CSS transition
- Approve/Reject decision card with color-coded visual system
- Responsive layout — works on mobile and desktop

## Model Details

### Training Methodology

The model is trained on a synthetically generated dataset of 1,500 samples designed to reflect real Indonesian Koperasi loan profiles:

```python
# Latent score formula (from train_model.py)
skor_laten = (
    (log(gaji_per_bulan) * 1.5)        # income capacity
    - (jumlah_tanggungan * 0.4)         # dependency burden
    - (riwayat_telat_bayar_hari * 0.05) # payment history
    + (lama_bekerja_bulan * 0.01)       # employment stability
    - (rasio_utang_saat_ini * 3.0)      # DTI risk
    + (log(nilai_agunan) * 0.5)         # collateral coverage
    + (persentase_kehadiran_rat * 0.015) # cooperative engagement
    + (lulus_diksar * 0.8)              # education certification
    + (ada_penjamin * 1.5)              # social guarantee
)
```

### XGBoost Configuration

```python
XGBClassifier(
    n_estimators=100,
    max_depth=4,
    learning_rate=0.1,
    subsample=0.8,
    colsample_bytree=0.8,
    eval_metric='logloss',
    random_state=42
)
```

### SHAP Feature Labels (Indonesian)

| Feature Key | Human Label |
|---|---|
| `gaji_per_bulan` | Kapasitas Pendapatan Bulanan |
| `rasio_utang_saat_ini` | Rasio Batas Utang terhadap Pendapatan (DTI Ratio) |
| `riwayat_telat_bayar_hari` | Rekam Jejak Keterlambatan Pembayaran (SLIK) |
| `nilai_agunan` | Estimasi Jaminan Likuidasi Nilai Agunan |
| `ada_penjamin` | Ketersediaan Penjamin/Avalis Kredit |
| `lulus_diksar` | Sertifikasi Pendidikan Dasar Koperasi |
| `persentase_kehadiran_rat` | Tingkat Kehadiran Rapat Anggota Tahunan (RAT) |
